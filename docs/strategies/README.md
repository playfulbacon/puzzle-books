# Strategy guides

Source text for the introduction that opens each genre section of the book. Each guide follows the same
shape so the sections read as one voice:

1. **What it is** — two or three sentences on the puzzle and why it is satisfying.
2. **The rules** — the same one-paragraph statement used on the puzzle pages.
3. **How to read the grid** — what each mark means and what a finished grid looks like.
4. **First moves** — the handful of things to look for before anything else; enough to start.
5. **Strategies** — ordered from the direct consequences of one clue up to the reasoning a hard puzzle
   needs. Each is named, states when it applies, what to do, and why it is true. The tier matches the
   difficulty band it first becomes necessary at.
6. **Things that go wrong** — the mistakes beginners make and how to notice them.

Every strategy here is also a candidate rule for the technique-ladder solver (PLAN.md §3.4). Once the
solver applies these same rules, the book's difficulty ratings will mean "the hardest strategy in this
guide that the puzzle needs", which is exactly what a reader wants a rating to mean.

Guides so far: [Masyu](masyu.md), [Hashiwokakero (Bridges)](hashiwokakero.md).
Each will get small before-and-after diagrams drawn with the book's own renderer.

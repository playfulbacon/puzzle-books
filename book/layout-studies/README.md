# Layout studies

Working files for the page-layout options shown on the design canvas. Each `*.dc.html` is one
7 × 10 in page (672 × 960 px at 96 px/in), black ink only, set as a right-hand page with a 0.75 in gutter.

- `Main.dc.html` — Option A, Quiet (Nikoli-like)
- `OptionB.dc.html` — Option B, Morning page
- `OptionC.dc.html` — Option C, Editorial
- `NurikabePage.dc.html`, `ShikakuPage.dc.html` — Option A applied to two more genres
- `Solutions.dc.html` — six solutions per page
- `canvas.json` — artboard positions and notes
- `build.mjs` — regenerates the pages from `samples.json` / `samples-b.json`
- `samples.mjs` — produces the sample puzzle graphics (valid structures, **not** verified unique;
  layout stand-ins until the real generators exist)

Type: Newsreader (headings, rules), IBM Plex Sans (labels, grid digits), Zen Old Mincho (Japanese names).
